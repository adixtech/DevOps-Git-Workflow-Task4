# Git Commands Reference

## Repository Commands
- `git init` – Initialize repository.
- `git status` – Check current status.
- `git log` – View commit history.
- `git diff` – View file changes.

## Branch Commands
- `git branch` – List branches.
- `git branch dev` – Create dev branch.
- `git switch dev` – Switch to dev branch.
- `git switch -c feature` – Create and switch to feature branch.

## Commit Commands
- `git add .` – Stage changes.
- `git commit -m "message"` – Create commit.

## Remote Commands
- `git remote -v` – View remote repositories.
- `git push -u origin main` – Push main branch.
- `git pull` – Download and integrate changes.

## Merge Commands
- `git merge feature` – Merge feature branch.
- `git merge dev` – Merge dev branch.

## Other Commands
- `git stash` – Temporarily save uncommitted changes.
- `git tag v1.0` – Create a version tag.
- `git tag` – List tags.
